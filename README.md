## 포트폴리오를 화면으로 보는 방법

위 주소를 누르면 브라우저에서 바로 열립니다. 설치나 내려받기는 필요 없습니다.

## 담은 것

`index.html` 한 장에 아래 순서로 적었습니다.

1. 부트캠프 동안 달라진 것 세 가지
2. 여정: 기초 → 팀 프로젝트 1(설비 상태 진단 대시보드) → 납기 알리미(개인) → 팀 프로젝트 2(StockPilot) → 팀 프로젝트 3(일터스텔라)
3. 한계와 다음에 할 것

단계마다 내가 한 일 / AI가 한 일 / 팀이 한 일을 나누고 커밋·PR·QA 기록·채점 결과 링크를 붙였습니다. 연습으로 만든 작은 것들은 넣지 않았습니다.

## 읽을 때 알아 둘 것

- 모든 화면은 가상 데이터나 합성 데이터입니다. 효과를 잰 숫자는 없습니다.
- 증거 링크 가운데 팀 저장소는 비공개라 권한이 있는 사람만 열립니다.
- 같이 만든 사람의 이름은 적지 않고 팀원 A·B·C로 적었습니다.
- 숫자는 2026년 11월 23일에 GitHub와 채점 결과 파일에서 센 값입니다.
