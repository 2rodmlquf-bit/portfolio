## 읽을 때 알아 둘 것

- 모든 화면은 가상 데이터나 합성 데이터입니다. 효과를 잰 숫자는 없습니다.
- 프로젝트마다 내가 한 일 / AI가 한 일 / 팀이 한 일을 나눠 적었습니다.
- 같이 만든 사람의 이름은 적지 않고 팀원 A·B·C로 적었습니다.
- 숫자는 2026년 11월 23일에 GitHub와 채점 결과 파일에서 센 값입니다.
- 날짜별 작업 기록은 날마다 쓴 일지가 아닙니다. 기간 동안 vibelog에 기록하지 못해서 제출일에 커밋과 PR 기록을 날짜별로 다시 모았습니다.
